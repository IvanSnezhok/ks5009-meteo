# Метеостанція KS5009 — Telegram Mini App

Сторінка, яку бот метеостанції відкриває кнопкою «Метео».

- `index.html` — сама сторінка (GitHub Pages), збирається скриптом `miniapp/build.py` поруч зі скетчем.
- гілка `data` — файл `data.bin`, який станція оновлює раз на 15 хв.

Дані зашифровані AES-256-GCM. Ключ є лише на станції й у кнопці бота (частина адреси після `#`,
яка не надсилається на сервер), тому з цього репозиторію їх не прочитати.
